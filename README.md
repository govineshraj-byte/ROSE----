# ROSÉ — Where Beauty Blooms

A luxury cinematic 3D rose experience. Next.js 16 + React 19 + Tailwind v4 +
React Three Fiber + a real-time canvas rose engine.

Live: https://rose-experience-kupiwap61-govineshs-projects.vercel.app

## Develop

```bash
npm install
npm run dev
```

## Deploy

Pushes to `main` auto-deploy to Vercel production.
